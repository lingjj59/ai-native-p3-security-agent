# CH01 候选：运行中撤销测试授权

状态：proposed；批准人/日期/旧基线/实施版本均待定。

业务理由：任务启动时获准不代表后续可永久执行。拟在第 k 次检查结束后由可信 runner 撤销目标授权，控制器每次启动前读最新版本，停止队列，保留历史和未覆盖。

保持不变量：未注册不执行、证据不足不通过、预算不扩大。非目标：更换整个业务、增加任意目标、模型自行重新授权。在途结束或取消边界待批准，不承诺瞬时取消所有动作。

验收方向：启动前撤权无新动作；在途动作按批准边界收尾，此后无新 execution_started；历史证据完整。影响 registry/controller/runner/report/Spec/Trace/回归/恢复。批准后填写影响、实际 Diff、失败复现、修复和伙伴复测；当前不作通过声明。
