# 教学实验环境

当前只有 `src/p3_agent/executor.py` 的内存模拟器，所有用户、凭据引用和标记均虚构。无监听端口，无网络请求，无真实数据。`public-fixtures/` 保存三个版本化的公开场景：

| Fixture | 输入变更 | 预期 |
| --- | --- | --- |
| good | 无覆盖 | 六项符合各自契约，均 NOT_CONFIRMED |
| known-bad | T02 返回 DB 教学标记 | T02 CONFIRMED，其余按契约 |
| timeout | T01 超时，消耗 90 逻辑秒 | T01 不足，停止后续启动，六项均无有效证据覆盖 |

预期只用于公开演示与测试，不作为真实运行结果；实际结果在 evidence。未来动态模型输入不能包含此表或 Fixture 缺陷开关。教师保留样本、答案不进入本目录。

本地 HTTP 服务属于 K04，尚未实现，教师环境未确认。不要将启动模拟命令写成“靶场服务已启动”。
