# Project Harness 清单

运行时为 Python 3.11+ 标准库 CLI，无安装步骤、无第三方运行依赖；编译/测试/场景命令见 [AGENTS](../AGENTS.md)。可选 pyproject 描述源码包，本次验收按仓库脚本运行，不要求构建 wheel。

| 项 | 冻结值 / 权威来源 |
| --- | --- |
| 源码与规格 | Git commit；Spec `p3-sim-contract-v0.1` |
| 注册目标/工具 | registry.py：一个纯模拟目标、六项；CLI 不接受任意目标 |
| 权限 | 无网络/模型客户端；Git 只读版本查询使用固定 argv，检查执行器无 Shell 能力 |
| 预算 | 8 尝试、8 决策、90 逻辑秒、单并发；CLI 只允许收紧尝试预算 |
| 检查 | unittest、compileall、check_docs、三场景演示；CI 运行前四项中的 Good |
| 证据 | JSON/JSONL、UUID run、SHA256；写入失败即停止 |
| 重试/恢复 | 无自动重试；新 run 重置内存状态，历史目录不覆盖 |
| 真实批准 | 由教师/有权目标拥有者给出，仓库设计不等于批准 |

可见性：用户与复核者可读公开 Fixture 和所有模拟证据；未来产品模型只能读任务、注册 ID 及必要观察，不能读 Fixture 缺陷开关/真值；评价器只读冻结契约和证据，不继承执行器能力；保留测试/答案由教师或独立 runner 保管。当前没有隐藏答案或教师成绩文件。

开发用 Codex 管理本次编辑与工具会话；不将开发平台能力算作交付产品的动态调度、隔离沙箱或评价器实现。零模型调用指**交付程序运行**，不指本次 AI 开发会话。开发会话 Token/费用不可得，披露为 unavailable。
