# P3 一页开题卡

日期：2026-10-13；状态：**开题提交稿，教师审批待确认**。

**题目**：本地教学文档服务的授权边界测试与证据复核 Agent——固定流程与证据驱动调度的对照实验。

**需求与用户**：课程开发组、结对复核组和教师需要一个在明确授权及预算内检查文档权限、能够追溯结论的工具，避免把超时误判为安全，或把少测包装成高效。

**三步流程**：①加载注册目标、六项检查和预算；②计划器提议 ID，独立控制器放行后执行并记录原始观察；③按证据报告确认问题/未确认/不足，列出未覆盖和停止原因。

**范围**：两名虚构用户 A/B、文档 DA/DB 和各自附件。学期范围包含固定/动态调度、只读评价器、一次运行中撤权 CH01、结对对抗和恢复。本次交付为离线模拟固定基线及开题材料。

**非目标**：公网扫描、真实校园系统与账号、任意 URL/Shell、自动扩权、自动修复任意目标、复杂前端和模型训练。

**三条不变量**：未注册目标/动作不执行；结论引用匹配版本的真实观察且不足不冒充安全；停止后不启动新检查并保留历史和未覆盖。

**验收与测试**：公开 Good 的正常读取/附件可用；Known Bad 中 A 读取 DB 返回教学标记时确认越权；超时必须不足；未知 ID 必须无执行。R01—R12、GWT-01—08 见[规格](specification.md)及[验收矩阵](acceptance-matrix.md)。保留测试建议覆盖不同 ID、故障位置、撤权时点和虚构引用，由教师/独立 runner 保管，目前未提供。

**取舍与实验**：比较固定顺序与依据证据动态选择是否更早发现问题，同时计入覆盖、错误和成本；唯一主要变量为调度策略。先完成模拟器，保留固定基线，不预设模型更好。见 [ADR-001](adr/001-simulator-first.md)。

**Change 与对抗**：候选 CH01 在第 k 次动作后撤销测试授权；教师批准后实施。两类对抗为工具超时/不足误判，以及工具诱导扩权/无效证据引用。当前不声称 CH01 已通过。

**数据、授权与恢复**：全部数据为本仓库公开虚构 Fixture；本次无目标网络访问，用户已授权仓库建设和提交。真实靶场、模型端点及费用另行确认。新 run 重新初始化；Ctrl+C 停止，历史证据保留，详见[运行手册](../release/README.md)。

**分工与复核**：A1/A2 真实姓名、学号待登记；按 K01—K08 交替实现/验证，结对组待确定。本次 AI 生成和本机检查不能替代两人个人贡献、伙伴复测及人工签署。教师可按提交入口运行三条场景命令并抽查三条 MUST。

**审批出口**：题目开放、人员/结对、真实目标授权、日期及正式 Rubric 均待确认，见[未决项](open-questions.md)。本卡不构成教师批准。
