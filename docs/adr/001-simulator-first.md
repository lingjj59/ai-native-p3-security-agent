# ADR-001：先完成零依赖离线模拟基线

日期：2026-10-13；状态：本次实现采用，课程验收与人工签署待确认。

问题：真实环境、模型端点、两人及结对信息尚未确认，但第一次任务需要可定位模块、可触发功能和可断言规格。

决定：采用 Python 标准库、注册六项动作、固定计划与独立控制器、三份公开 Fixture 和 JSONL 证据。把模型动态调度和真实服务留在 K04/K05，评价器留在 K06。

理由：读者无需密钥或联网即可复现权限门、正常响应、已知越权和超时差异；既能提交真实 GWT 功能，又不把外部授权写成既成事实。备选为立即接模型/本地 HTTP 服务，当前会引入未冻结的授权、依赖和费用。

代价：纯模拟不能证明真实 HTTP 权限、网络隔离、并发在途停止、模型抗注入或独立评价。固定计划读不到动态新信息，不能由本次结果推断 F/D 优劣。后续必须在共同控制器与证据格式上补对照实验。

证据：本次测试记录和三场景运行见首次提交入口。AI 做出了本次实现选择；未伪造人类审查、教师批准或故意制造的 AI 错误。
