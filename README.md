## 已确定的选题

**本地教学文档服务的授权边界测试与证据复核 Agent——固定流程与证据驱动调度的对照实验。**

首版围绕一个本地教学文档服务、两名虚构用户、两份文档及附件、六项注册检查展开。先完成模拟器与独立控制器，再接入获批准的本地执行环境；比较固定流程与模型动态调度，并完成运行中撤权、受控对抗、证据复核和恢复交接。
